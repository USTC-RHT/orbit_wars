3 输出动作

三头联合采样：fire (Bernoulli) → target (Categorical) → amount (Categorical)。

网络先输出离散决策，再转换为游戏动作：

[from_planet_id, angle_rad, ships]
Step 1 · Fire是否发射，训练 Bernoulli 采样，推理 sigmoid > 0.5
Step 2 · Target合法目标中 categorical 采样，推理 argmax
Step 3 · Amount8 个派兵档位中 categorical 采样，推理 argmax
Step 4 · Aim物理层把目标星球转换为实际发射角度

联合 log probability

logp = log p(fire) + fire * (log p(target) + log p(amount))
不发射时，只学习 fire 头；target 与 amount 不计入该样本 logp。

4 物理层动作转换

通过 actions_from_decisions_with_policy_mask 与 aim_with_prediction_jax 完成。

  • 根据派兵数量计算舰队速度
  • 在 60 步窗口内预测目标位置
  • 支持旋转星球和彗星目标
  • 搜索可命中时间，并检查附近整数回合
  • 验证路径不撞太阳、不出界
  • 验证第一碰撞对象就是目标星球
如果模型想发射但物理层判定不可达，动作会变成 no-op； 这类样本不会进入 PPO policy loss，避免用错误动作概率更新策略。

5 训练方式 (PPO)

标准 PPO clipped objective + GAE，多 epoch 更新，KL 早停保护。

单个 update 流程

1并行运行 num_envs 个环境
2收集 rollout_steps 步轨迹
3每步编码状态 → 采样 fire/target/amount → 转换动作
4记录 old logp、old value、reward、done、mask
5用 GAE 计算 advantage 与 return
6PPO clipped objective 多 epoch 更新
7记录 loss / entropy / KL / win rate

PPO 细节

  • policy loss：标准 PPO clip
  • value loss：value clipping
  • advantage：可选 batch 内归一化
  • KL 早停：approx_kl > 1.5 × target_kl 时提前结束剩余 epoch
  • 优化器：Adam + global norm clipping
  • 学习率：支持 constant / linear / warmup_cosine
  • 熵：fire / target / amount 三头独立系数，并支持 entropy schedule

6 多种对手设置

通过 opponent 与 pool_mode 控制对手行为。

① Current

配置：cfg_jax_selfplay_current.yaml
opponent: pool
pool_mode: current

全程对 selfplay-current 训练，每个 update 前同步 learner 参数给对手。最像纯 self-play，目标变化最快。

② Lag Checkpoint

配置：cfg_jax_selfplay_lag_checkpoint.yaml
pool_mode: lag_checkpoint
pool_lag_interval: 50

Phase 1 只打 50 update 前的 lag；Phase 2 在 current 与 lag 间采样。降低非平稳性。

③ Fixed Pool

配置：cfg_jax_selfplay_fixed_pool.yaml
pool_mode: fixed_pool

Phase 1 在 nearest / current / lag 中均匀采样；达 nearest eval 晋级条件后切到 Phase 2。

④ PFSP

配置：cfg_jax_selfplay_pfsp.yaml
pool_mode: pfsp
pool_max_size: 4

采样权重 ≈ (1 − winrate + 0.1)²，越打不过越被采到，自动聚焦短板。

其他兼容模式

  • opponent: nearest：只打最近目标启发式
  • opponent: self：旧版 self-play，由 self_play_update_interval 控制
  • opponent: checkpoint：固定 checkpoint 对手
  • pool_mode: snapshot：按间隔保存历史快照，比例混合 current 与 snapshot

由 reward_from_transition 计算。当前主原则：关闭 dense shaping，主要靠终局胜负。

联合 entropy 分解

entropy = entropy_fire + fire * (entropy_target + entropy_amount)
target / amount 熵主要反映真实发射样本中的探索程度。 三头分开看，能更快判断是 fire 塌缩、target 塌缩，还是 amount 过于确定。
