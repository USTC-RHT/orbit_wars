# 游戏规则详解

> **所属页面**：[Home](Home.md) > 游戏规则详解

## 1. 棋盘与太阳

| 属性 | 值 |
|------|----|
| 棋盘尺寸 | 100×100 连续空间，原点在左上角 |
| 太阳位置 | 中心 (50, 50)，半径 10 |
| 对称性 | 4 重镜像对称：(x,y), (100-x,y), (x,100-y), (100-x,100-y) |

**太阳碰撞规则**：舰队飞行路径（线段）与太阳圆形区域相交时，舰队立即被摧毁。碰撞检测为连续检测（基于路径线段，非终点）。

## 2. 星球

### 2.1 星球字段

```
[id, owner, x, y, radius, ships, production]
```

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识符 |
| `owner` | 玩家 ID（0–3），`-1` 表示中立 |
| `x`, `y` | 当前位置坐标 |
| `radius` | 由产能决定：`1 + ln(production)` |
| `ships` | 当前驻守船数 |
| `production` | 产能（1–5），每回合生产对应数量的船 |

### 2.2 星球类型

| 类型 | 判定条件 | 行为 |
|------|----------|------|
| **轨道星球** | `orbital_radius + planet_radius < 50` | 以 0.025–0.05 rad/turn 绕太阳旋转（每局随机，全局一致） |
| **静态星球** | 距中心较远 | 不旋转，坐标固定 |

### 2.3 地图构成

- 总星球数：20–40 个（5–10 个对称组，每组 4 颗）
- 至少 3 组为静态星球
- 至少 1 组为轨道星球
- 1 组被随机选为**起始星球组**

### 2.4 起始星球

| 玩家数 | 分配方式 |
|--------|----------|
| 2 人局 | 起始组中对角线对立的 2 颗（Q1 和 Q4） |
| 4 人局 | 起始组中 4 颗各占一颗 |

起始星球初始驻守：**10 艘船**。

## 3. 舰队

### 3.1 舰队字段

```
[id, owner, x, y, angle, from_planet_id, ships]
```

| 字段 | 说明 |
|------|------|
| `angle` | 飞行方向（弧度） |
| `ships` | 船数（飞行中不变） |

### 3.2 飞行速度

速度基于船数对数缩放：

$$
v = 1.0 + (v_{max} - 1.0) \times \left(\frac{\ln(\text{ships})}{\ln(1000)}\right)^{1.5}
$$

其中 $v_{max} = 6.0$（单位：格/回合）。

| 船数 | 近似速度 |
|------|----------|
| 1 | 1.0 |
| ~500 | ~5.0 |
| 1000 | 6.0 |

### 3.3 飞行与销毁规则

舰队以固定方向匀速直线飞行，在以下情形被移除：

1. **越界**：离开 100×100 棋盘
2. **撞太阳**：路径线段进入太阳半径范围
3. **撞星球**：路径线段进入任意星球半径范围（触发战斗）

### 3.4 发射规则

每回合提交的指令格式：`[from_planet_id, direction_angle, num_ships]`

- 只能从己方星球发射
- 船数不得超过该星球当前驻守数
- 舰队从星球半径外侧指定方向生成
- 同一颗星球可在同一回合发射多支舰队

## 4. 彗星

彗星是飞越棋盘的临时天体，遵循高度椭圆轨道。

| 属性 | 值 |
|------|----|
| 半径 | 1.0（固定） |
| 产能 | 1 船/回合（被占领时） |
| 初始船数 | 随机偏低（4 次 1–99 随机取最小值），同组 4 颗共享 |
| 飞行速度 | 默认 4.0 格/回合 |
| 出现时机 | 每局第 50, 150, 250, 350, 450 回合各生成 1 组（4 颗，每象限 1 颗） |

**关键规则**：
- 彗星飞出棋盘时，其上所有驻守船数一并消失
- 彗星消失在发射指令处理之前，故不能在消失同一回合从彗星发兵
- `comet_planet_ids` 字段标识当前哪些 planet ID 是彗星

---

## 5. 回合顺序（Turn Order）

每回合严格按以下顺序执行：

```
1. 彗星消失检测：移除已飞出棋盘的彗星
2. 彗星生成：在指定回合（50/150/250/350/450）生成新彗星组
3. 舰队发射：处理所有玩家的动作指令，生成新舰队
4. 生产：所有已占领星球（含彗星）产出船只
5. 舰队移动：所有舰队前进，检测越界/太阳/星球碰撞，触发战斗队列
6. 星球旋转 & 彗星移动：轨道星球旋转，彗星沿轨迹前进，扫过舰队触发战斗
7. 战斗结算：处理所有待结算的战斗
```

---

## 6. 战斗系统

当一支或多支舰队碰撞某颗星球时，触发战斗：

### 6.1 多方战斗规则

1. 所有到达舰队按所属玩家分组，同方船数求和
2. 船数最多的攻击方与第二多的攻击方交战，胜者为差值方
3. 若存在幸存攻击方：
   - 幸存方为**星球同一所有者** → 幸存船数加入驻守
   - 幸存方为**不同所有者** → 与星球驻守军交战：
     - 攻击船数 > 驻守船数 → 星球易主，新驻守数 = 攻击船数 - 驻守船数
     - 攻击船数 ≤ 驻守船数 → 攻击失败，驻守数减少
4. 若**两个攻击方平局** → 所有攻击船数全部归零（无人幸存）

### 6.2 战略含义

- 多路同时进攻同一目标可造成"两败俱伤"，需谨慎利用
- 防守方只需维持 ≥ 攻击方船数的驻守即可击退
- 运动中的星球**主动扫过**飞行舰队也会触发战斗

## 7. 胜负判定

### 7.1 终局条件

| 条件 | 说明 |
|------|------|
| 回合耗尽 | 达到 500 回合上限 |
| 玩家淘汰 | 一名玩家（或更少）仍拥有星球或舰队时，游戏结束 |

### 7.2 得分计算

$$
\text{最终得分} = \sum_{\text{己方星球}} \text{驻守船数} + \sum_{\text{己方舰队}} \text{舰队船数}
$$

得分最高者获胜。

## 8. 轨道预测（策略关键点）

轨道星球的当前位置可通过以下公式从初始状态预测：

$$
\theta_t = \theta_0 + \omega \cdot t
$$

$$
x_t = x_{sun} + r \cos(\theta_t), \quad y_t = y_{sun} + r \sin(\theta_t)
$$

其中：
- $\omega$：`angular_velocity`（全局统一，每局随机）
- $r$：轨道半径（从 `initial_planets` 初始位置计算）
- $t$：当前回合数

**实战要点**：向运动星球发兵时，必须预测 ETA 步后的目标位置，计算提前量角度，否则舰队会错过目标。
